# Inspired Education brand assets

Public website reference inspected on 15 October 2026: https://www.inspirededu.com/

The supplied reference inspiredschools.com returned a parking page at /lander. Inspired Education's official inspirededu.com website was used instead.

## Verified identity

Official website palette: navy #122147, heading navy #143256, secondary blue-gray #5B7A95, secondary dark #415165, blue #1B75BB, sand #EED6AB. Darker instructional body text is used for legibility.

Current palette source:
https://d24d7vsshzrslo.cloudfront.net/sites/company/files/color/born_ready_bs4_bahamas-4cc60c4a/colors.css?tmkw4j

Official typography: Roboto for headings, links and buttons; Open Sans for body copy. Regular-weight display headings, pill-shaped actions, genuine wordmark, white space and navy/blue visual hierarchy are adapted for learning rather than reproducing the marketing video hero.

Typography source:
https://d24d7vsshzrslo.cloudfront.net/profiles/custom/born_ready_profile/themes/born_ready_bs4/css/fonts/roboto_opensans.css?tmkw4j
